💸 Financial Risk Predictor
Sistema de previsão de risco financeiro pessoal

📌 Sobre o Projeto
O Financial Risk Predictor é um projeto de estudo e portfólio que tem como objetivo prever risco de quebra financeira pessoal a partir da análise de renda, gastos e comportamento financeiro ao longo do tempo. A ideia é ir além de apenas mostrar dados históricos, criando um sistema que antecipe problemas financeiros e ajude na tomada de decisão.

🎯 Motivação
Grande parte das pessoas só percebe que está em dificuldade financeira quando: o saldo já está negativo dívidas começam a se acumular decisões importantes já foram tomadas sem planejamento.
Este projeto busca explorar como análise de dados e machine learning podem ser usados para criar um alerta preventivo, mesmo com dados simples.

🧠 O que o sistema faz
- Analisa histórico financeiro do usuário
- Identifica padrões de gasto e comprometimento de renda
- Estima a probabilidade de risco financeiro futuro
- Retorna um score de risco e visualizações claras
- O foco não é apenas o modelo, mas o entendimento do problema e da solução como produto.

📥 Entrada de Dados:
O sistema trabalha com informações como:
  - Renda mensal
  - Gastos mensais categorizados
  - Saldo ao longo do tempo
  - Compromissos financeiros recorrentes
* Para fins de aprendizado, o projeto utiliza dados sintéticos, simulando cenários realistas.

⚙️ Processamento dos Dados
- Limpeza e padronização dos dados
  Criação de features como:
  - Taxa de comprometimento da renda
  - Variação mensal de gastos
  - Tendência de saldo
  - Organização dos dados para análise temporal
* Essa etapa foi fundamental para entender como boas features impactam diretamente o modelo.

🤖 Modelo Preditivo
Modelos de Machine Learning supervisionados
Previsão de risco em janelas futuras (ex: 30, 60 e 90 dias)
Resultado apresentado como score de risco (0–100)
  O projeto também compara:
  - Abordagens baseadas em regras simples
  - Modelos de machine learning

📊 Visualização
Dashboard simples para acompanhamento financeiro
Indicadores visuais de risco
Gráficos de evolução de saldo e gastos
O foco do dashboard é clareza, não complexidade.
