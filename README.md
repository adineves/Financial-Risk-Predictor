💰 Financial Risk Predictor
Sistema de análise de risco financeiro desenvolvido em Python, com foco em organização de dados financeiros pessoais, geração de indicadores e avaliação de cenários de risco. 
Projeto nasceu da necessidade de entender melhor a própria situação financeira e evoluiu para uma solução estruturada, com potencial de expansão para dashboards, previsões e aplicações futuras.

📌 Objetivo do Projeto
- Centralizar dados financeiros mensais
- Calcular indicadores financeiros automaticamente
- Avaliar risco financeiro com base em regras claras
- Servir como base para estudos em análise de dados e IA
- Evoluir futuramente para um produto utilizável por outras pessoas

🧠 Funcionalidades Atuais
- Leitura de dados financeiros reais via CSV
- Padronização e tratamento de dados
- Cálculo automático de:
  - Gastos totais
  - Saldo mensal
  - Comprometimento da renda
  - Variação de saldo
  - Média móvel de gastos
- Sistema de regras para avaliação de risco financeiro
- Retorno padronizado com:
  - Score de risco (0 a 100)
  - Nível de risco (baixo, médio ou alto)
  - Motivos identificados

🛠️ Tecnologias Utilizadas
- Python 3
- Pandas
- Estrutura modular (boas práticas de organização)
- Git / GitHub
